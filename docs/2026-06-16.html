Iroh 1.0: Internet Addressing by Key Not IP

The Iroh peer-to-peer networking library has reached version 1.0, introducing a paradigm where devices are addressed by cryptographic keys rather than IP addresses. The project has already seen over 200 million endpoints created in the past 30 days across millions of devices worldwide.

  • 200+ million endpoints created in the last 30 days on Iroh's public relays
  • Built on QUIC protocol with NAT traversal and multipath support
  • Used for LLM training, video streaming, agent communication, and secure messaging

Why it matters: Replacing IP addresses with cryptographic keys would make devices permanently addressable regardless of network changes, solving a foundational problem that has plagued peer-to-peer computing for decades.
