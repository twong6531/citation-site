🔓 Critical Auth Bypass Lets Hackers Flash Motorola Routers

A security researcher disclosed an unauthenticated remote code execution vulnerability in Motorola's MR2600 Wi-Fi 5 router, allowing any attacker on the LAN to flash arbitrary firmware without credentials. The flaw stems from a logic error: the router checks allowlisted paths with substring matching but checks denylisted paths with exact equality, making the bypass trivial.

  • Motorola MR2600 firmware upload and flash endpoints both lack proper authentication due to URI comparison bug
  • No cryptographic signing is required — any valid SEAMA-format firmware image can be flashed
  • Attack appends '?Login.html' to bypass auth: substring check passes, exact-match block never fires

Why it matters: Home routers are the gateway to every device on a network, and a firmware-level takeover gives attackers persistent, undetectable control of all traffic.
