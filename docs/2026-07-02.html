Tech Linux Encryption Flaw 🔐

Linux LUKS Encryption Keys Exposed for 2+ Years

Since Linux 6.9 (May 2024), a silent refactoring bug left full-disk encryption keys resident in RAM during laptop suspend, enabling cold-boot key extraction attacks for over two years. The bug was introduced by a routine and sensible-looking code change that nobody caught.

  • Bug persisted undetected across kernel versions 6.9 through recent releases — 2+ years
  • LUKS protects data on an estimated hundreds of millions of Linux-based devices
  • Only affects suspend mode; full shutdowns correctly cleared encryption keys

This silent regression undermined the fundamental security guarantee of full-disk encryption for Linux users for over two years without detection.
