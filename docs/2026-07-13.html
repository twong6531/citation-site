02 TECH Linux Security 🐧 Impact 9/10

GhostLock: 15-Year Kernel Bug Hits All Linux Distros

Security researchers at nebusec disclosed GhostLock, a stack use-after-free (UAF) vulnerability in the Linux kernel's io_uring subsystem that has existed since approximately 2009. The flaw affects every Linux distribution and can be exploited for local privilege escalation, making it one of the longest-lived critical kernel vulnerabilities ever disclosed.

  • HN score: 345 — high community alarm from a deep-dive security research post
  • Vulnerability present for ~15 years across all Linux distributions (since ~2009)
  • Exploits the io_uring subsystem via stack use-after-free, enabling privilege escalation

Every Linux server, desktop, and embedded device worldwide carries this bug — patch urgency is extreme given the exploit surface is the ubiquitous io_uring interface.
