01 Tech Kernel Security Flaw 🔑

Linux Bug Left Encryption Keys in RAM 2 Years

A regression introduced in Linux kernel 6.9 (May 2024) caused LUKS full-disk encryption to silently fail during laptop suspend, leaving master decryption keys resident in RAM for over two years. Any attacker with physical access to a sleeping laptop could have extracted the key, defeating the entire purpose of disk encryption.

  • Bug present since Linux 6.9 released May 2024 — over 2 years undetected
  • Affects all Linux users with LUKS full-disk encryption using suspend-to-RAM
  • LUKS key wipe still worked on full shutdown, but sleep/suspend (the common case) was broken

02 Tech Compiler Bootstrapping 🦀

Rust Compiler Entirely Translated into C Code

Developer FractalFir completed crustc, a project that translates the entire Rust compiler (rustc) — a ~400,000 line Rust codebase — into equivalent C code. This extraordinary feat allows Rust programs to be bootstrapped from a C compiler, removing the circular dependency on an existing Rust installation.

  • Rustc is approximately 400,000 lines of complex Rust code
  • C translation enables bootstrapping Rust from scratch using only a C compiler
  • Project removes the 'requires Rust to compile Rust' chicken-and-egg problem
